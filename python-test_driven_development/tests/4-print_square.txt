The print_square function prints a square of the given size using '#'
and validates input types.

>>> print_square = __import__('4-print_square').print_square

# Normal squares
>>> print_square(4)
####
####
####
####

>>> print_square(10)
##########
##########
##########
##########
##########
##########
##########
##########
##########
##########

>>> print_square(1)
#

>>> print_square(0)
# (prints nothing)

# Invalid types
>>> print_square("3")
Traceback (most recent call last):
TypeError: size must be an integer

>>> print_square(3.5)
Traceback (most recent call last):
TypeError: size must be an integer

>>> print_square(-1)
Traceback (most recent call last):
ValueError: size must be >= 0
